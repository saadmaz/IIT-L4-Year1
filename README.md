# First Year Computing Modules Repository

This repository contains all academic materials from my **First Year (Level 4)** of the Computing degree program at the **Informatics Institute of Technology (IIT), Sri Lanka**, which is affiliated with the **University of Westminster**.

It includes lecture materials, tutorials, practical exercises, coursework implementations and supporting resources that build the core skills for software engineering and computer science.

## 🛠 Running the Code

- **Python programs:** need only a standard Python 3 installation. Run any script with `python "<file>.py"` from its folder. The Software Development I coursework uses the `graphics.py` module included next to it.
- **Java coursework:** open the project folder in IntelliJ IDEA or compile the files in `src/` with `javac` and run the main class.
- **JavaFX practice project:** run `mvnw javafx:run` (or `./mvnw javafx:run`) from its folder.
- **Websites:** open the `.html` files in a browser.
