# First Year – Computing Modules Repository

This repository contains all academic materials from my **First Year** of the Computing degree program at **Informatics Institute of Technology (IIT), Sri Lanka**, affiliated with the **University of Westminster**.

It includes foundational learning materials, practical exercises, coursework, and supporting resources that build the core skills required for software engineering and computer science.

---

## 📚 Modules Covered

### 🔹 Software Development I
- Programming fundamentals
- Problem-solving and algorithmic thinking
- Introduction to structured programming concepts

### 🔹 Mathematics for Computing
- Discrete mathematics
- Logic, sets, and functions
- Mathematical foundations for computer science

### 🔹 Trends in Computer Science
- Emerging technologies
- Industry trends and innovations
- Research-oriented thinking

### 🔹 Computer Systems Fundamentals
- Computer architecture basics
- Hardware and software interaction
- Operating system fundamentals

### 🔹 Software Development II
- Object-oriented programming fundamentals
- Classes, objects, and methods
- Program design and best practices

### 🔹 Web Design and Development
- HTML5 and CSS fundamentals
- Basic JavaScript
- Responsive web design principles
- UI/UX basics

### 🔹 Other Modules
- Revision material from modules outside this Level 4 programme, kept for reference
  (a Java OOP in-class test and a Business Computing portfolio task)
