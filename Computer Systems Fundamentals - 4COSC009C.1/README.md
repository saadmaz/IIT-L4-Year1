## 📑 Weekly Content Overview

### Week 01 – Introduction to Computer Systems
Introduces fundamental computer system concepts, including hardware, software, and system components. This week provides the base required to understand all subsequent topics.

---

### Week 02 – Number Systems & Binary Arithmetic
Covers binary operations, hexadecimal representation, signed and unsigned integers, and range calculations. These concepts form the mathematical foundation of computer systems.

---

### Week 03 – Real Numbers & Floating-Point Representation
Focuses on representing fractional values in binary and explains the IEEE 754 floating-point standard. Tutorial PDFs provide step-by-step explanations and examples.

---

### Week 04 – Data Representation & Storage
Explores how different types of data are stored and represented, including character encoding systems and image representation techniques.

---

### Week 05 – Boot Process
Covers the Master Boot Record (MBR) and explains how a computer system initializes and loads an operating system.

---

### Week 06 – Operating Systems
Introduces operating system concepts, including system responsibilities and core abstractions that manage hardware and software interaction.

---

### Week 08 – Computer Architecture & Disk Scheduling
Discusses CPU architecture, instruction execution, and disk scheduling algorithms, focusing on system performance and efficiency.

---

### Week 09 – Disk Structure & Partitioning
Explains disk partitioning, sector structures, and low-level disk organization, providing insight into how storage devices are managed.

---

### Week 10 – IP Addressing
Introduces IP addressing concepts and address structures, forming a foundation for computer networking topics.

## 🚀 How to Use This Repository

1. Clone or download the repository
2. Navigate to the relevant week folder
3. Start with lecture slides, followed by PDF tutorials
4. Revise earlier weeks regularly, as concepts build progressively
5. Use PDFs as quick revision resources before exams

## 🎯 Recommended Study Path

1. Study the content in weekly order
2. Practice binary and number system questions frequently
3. Spend extra time on IEEE 754 and data representation topics
4. Focus on diagrams when studying architecture and operating systems
5. Revise IP addressing alongside networking modules
